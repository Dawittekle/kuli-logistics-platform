# Project Overview

Kuli is a peer-to-peer logistics and transport coordination platform. It connects clients who need goods moved with verified truck owners who can accept transport jobs.

## Project Goal

The system should make local transport easier to request, match, manage, and monitor. It is not designed to physically handle goods or take legal responsibility for disputes in the first phase. Instead, it acts as a trusted connector between clients, truck owners, call-center assistants, and administrators.

## Initial Scope

- Launch city: Addis Ababa
- Cash-first payment support
- Manual trip status updates instead of real-time GPS tracking
- Future-ready design for digital payments and real-time tracking
- Role-specific interfaces for clients, truck owners, call-center assistants, and admins

## User Roles

- Client: creates Kuli requests, views quotes, tracks request status, rates services, and reports issues.
- Truck Owner: registers vehicles, submits verification documents, receives matching requests, accepts jobs, and updates job status.
- Call-Center Assistant: helps users create bookings, manage tickets, and support clients who cannot directly use the app.
- Admin: verifies vehicles, manages users, handles reports, configures pricing rules, and monitors platform activity.

## Core Features

- Registration and login
- Role-based dashboards
- Vehicle registration and approval
- Kuli request creation
- Price estimation
- Matching and assignment
- Request status updates
- Assisted booking
- Notifications
- Ratings and reports
- Admin reporting and audit logs
